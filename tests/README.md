# Tests

The initial scaffold uses Vitest for baseline TypeScript test execution.

Current scope:

- Tooling sanity tests only.

Future testing layers may include:

- Unit tests for test-step models and locator logic.
- Integration tests for local storage and report generation.
- Browser automation tests for recording and playback.
- Snapshot or approval tests for reports.
- Packaging validation for Windows x86/x64.
- Packaging validation for Windows on ARM.
