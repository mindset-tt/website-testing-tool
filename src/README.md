# Source

This directory now contains the initial Electron + React + TypeScript tooling scaffold for the MVP.

Current scope:

- Electron main process.
- Secure preload bridge.
- React renderer app shell and empty states.
- Shared preload API type.
- Local project schema types.
- Minimal local project create/open/save plumbing.
- Reserved folders for automation, storage, and reporting.

Not implemented yet:

- Recorder.
- Playwright automation.
- Test runner.
- Reports.
- Product workflows.
