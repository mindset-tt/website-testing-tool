# Non-Goals

This product needs discipline early. These are things the project will not try to do at the beginning.

## Early Non-Goals

- Not a cloud-first platform at the beginning.
- Not a full enterprise ALM replacement.
- Not a load testing tool.
- Not a mobile testing tool initially.
- Not trying to clone every competitor feature.
- Not sacrificing reliability for flashy AI features.
- Not building a huge integrations marketplace before the core test loop works.
- Not requiring every user to write code.
- Not hiding browser automation failures behind vague messages.
- Not optimizing for demos at the cost of maintainability.

## Why These Non-Goals Matter

The product has a large possible surface area. Early focus should stay on the core user loop: record, edit, run, diagnose, and maintain website tests locally. Features outside that loop should wait until the foundation is reliable.
